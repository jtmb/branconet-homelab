# ImageSharp 3.2.0: exact per-advisory attribution

The five unique advisories produce 18 high and 12 medium rows in each exact image scan. Each row repeats across six dependency graphs. Every current maintainer advisory explicitly identifies 3.2.0 as patched, and its concrete backport commits are verified ancestors of the official package source revision. No unmatched ImageSharp advisory remains in this bounded set. Raw scanner findings remain unchanged.
