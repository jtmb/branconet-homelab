# Calico 3.33 compatible remediation proposal — 2026-10-25

It needs **three coordinated images and ten Go executables**, including the separately built CSI registrar and node mount helper. Retained scans attribute **43 available C/H rows to Go/x/net**, **nine more to node EL9 packages**, and five node High rows to packages with no fixed version in that evidence. These are package/target rows, not unique exploits or a claim that an unbuilt replacement fixes them.

This is a source and ownership proposal only. No registry manifests/layers, SDKs or dependency archives were acquired; no build, test, scan, cluster mutation or Git operation was performed. Small official source/module metadata is retained on native F.
